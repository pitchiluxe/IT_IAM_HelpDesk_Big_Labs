Getting Started

Up and Running in Minutes

1

Download the installer

Click the Download button to get the latest Windows executable from the GitHub Releases page.

2

Install Ollama

Download and install Ollama from ollama.com/download, then pull a model:

ollama pull llama3.2

3

Run the application

Launch the installed application. It starts a local server and opens the desktop in your browser automatically.

4

Log in and start learning

Use the credentials shown on the login screen. Open the Lab Roadmap from the desktop to begin the guided labs.
